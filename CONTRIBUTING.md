# Contributing

This project is an engineering hypothesis. Contributions that increase falsifiability or close open problems are preferred.

## Preferred contributions

- Correctness proofs or counter-examples for any claim in the paper
- Complete, synthesizable RTL that meets the resource targets of Section 8
- Power and latency measurements on real silicon following the benchmark protocol
- Clean implementations in other languages that stay faithful to the pseudocode
- Closure of any item in `open_problems/`

## Style

- Prefer clarity over cleverness
- Keep the mathematical notation of the paper when writing formal comments
- Do not introduce new free parameters without documenting them in the calibration section

## Pull requests

1. Fork the repository
2. Create a branch named after the problem or feature
3. Open a pull request with a clear description of what was changed and why
4. Reference the corresponding open-problem ID if applicable
